# CampusPilot 物理数据模型

> 基于 `backend/app/modules/*/models.py` SQLAlchemy ORM 模型提取。
> PostgreSQL 17，5 个 Schema，68 张表。

---

## 总体概览

| Schema | 模块 | 表数 | 说明 |
|---|---|---|---|
| `platform` | M4 公共基础与平台治理 | 12 | 用户/角色/权限/Token/敏感词/审核/配置/幂等/审计 |
| `campus_service` | M2 校园服务中心 | 16 | 校区/部门/办事指南/工单状态机/电费 |
| `community` | M3 校园社区与互助 | 10 | 话题/帖子/评论/反应/举报/活动/报名/失物招领/匹配/认领 |
| `ai_knowledge` | M1 AI 与知识库 | 12 | 知识库/文档/入库/切片/会话/消息/引用/反馈/LLM调用 |
| `agent_platform` | M5 智能体与模型工程 | 18 | Agent/Tool目录/数据集/训练/模型/评估/AgentRun/Step/ToolCall/审批/Handoff/运行时命令/Checkpoint/事件流 |
| **合计** | | **68** | |

**通用约定：**

- 所有 UUID 主键使用 `gen_random_uuid()` 生成
- 所有 `created_at`/`updated_at` 使用 `TIMESTAMPTZ` 且默认 `now()`
- 软删除用 `deleted_at TIMESTAMPTZ`，部分唯一索引条件 `WHERE deleted_at IS NULL`
- 乐观锁用 `version INTEGER DEFAULT 1 CHECK(>=1)`
- JSONB 字段均有 `CHECK(jsonb_typeof(...) = 'object'/'array')` 类型约束
- VARCHAR 的 CHECK 约束使用 PostgreSQL 正则语法 `~ '^...$'`

## 附录：外键删除策略

| 策略 | 场景 |
|---|---|
| `CASCADE` | 子实体随父实体删除（如 Run 删除时级联 Step/ToolCall/Checkpoint） |
| `RESTRICT` | 被引用时禁止删除（如 Role 被用户持有时不可删） |
| `SET NULL` | 删除后保留引用痕迹（如 `assigned_to`、`reviewer_id`） |
